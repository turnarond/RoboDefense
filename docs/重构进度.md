## 架构决策

### 渲染架构
```
RoboDefenseGame
  ├── CameraManager (视图管理)
  ├── GameWorldRenderer (世界对象渲染)
  ├── HudRenderer (HUD 渲染)
  ├── UiRenderer (UI 控件渲染)
  └── GameLoop (固定时间步长)
```

### 平台抽象
```
core 模块 (纯 Java)
  ├── GameRenderer 接口
  ├── GameAudio 接口
  ├── GameStorage 接口
  ├── GameInputHandler 接口
  └── NetworkClient 接口

libGDX 实现
  ├── LibGdxRenderer (SpriteBatch + ShapeRenderer)
  ├── LibGdxAudio (Sound)
  ├── LibGdxStorage (Preferences + Files)
  └── NoOpNetworkClient (离线模式)
```

### 下一步建议

1. **立即可以做的**: 继续 Phase 3 核心逻辑迁移（纯 Java 类，无 Android 依赖）
2. **需要 Android Studio 的**: 验证 Android 构建（Task 1.10）
3. **依赖 Phase 3 的**: Phase 7-9（音频、输入、场景管理）
