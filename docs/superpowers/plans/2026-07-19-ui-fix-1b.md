### Task 1: P0-1 混合器箭头扩大 + P0-2 升级对话框遮罩/暂停

**Files:**
- Modify: `core/src/main/java/com/rdefense/core/scene/LevelSelectScreen.java:372-376`
- Modify: `core/src/main/java/com/rdefense/core/render/UiRenderer.java`

- [ ] **Step 1: P0-1 — 混合器 ▲/▼ 按钮从 18x12 → 24x16**

LevelSelectScreen.java 约 372-376 行，`drawRect(dx+8, dy-14, 18, 12, ...)` 和 `drawRect(dx+8, dy+16, 18, 12, ...)` 的宽度从 `18` 改为 `24`，高度从 `12` 改为 `16`。相应调整相邻文字位置（`dy-13`→`dy-12`, `dy+16`→`dy+18` 保持居中对齐）。

- [ ] **Step 2: P0-2 — 升级对话框加遮罩层**

在 `UiRenderer.renderUpgradeDialog()` 方法中 `renderer.begin()` 之后、面板绘制**之前**，增加全屏遮罩：
```java
        renderer.drawRect(0, 0, renderer.getScreenWidth(), renderer.getScreenHeight(),
                0f, 0f, 0f, 0.35f);
```
遮罩 alpha=0.35（屏幕其余区域变暗，突出对话框）。

- [ ] **Step 3: P0-2 — 升级对话框打开时暂停游戏**

在 `GamePlayScreen` 中调用 `uiRenderer.renderUpgradeDialog()` 的上下文——搜 `activeTowerId >= 0` 或 `upgradeDialog.visible`——追加 togglePause 调用。具体：当 `upgradeDialog` 从不可见变为可见时，如果 `runState == GAME_RUNNING || runState == GAME_FAST_FWD`，调用 `gameState.togglePause()`。

注意：需要新增状态跟踪以区分"对话框首次打开触发 pause"vs"每帧调用重复 pause"。用字段 `private boolean upgradeDialogWasVisible = false;` 跟踪上一帧状态。

```bash

git commit -m "fix: P0 混合器箭头24x16 + 升级对话框遮罩与自动暂停"
```
