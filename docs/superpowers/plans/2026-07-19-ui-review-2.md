### Task 1: 渲染管线诊断

**Scope:** GamePlayScreen + UiRenderer + GameWorldRenderer 的渲染效率

利用已知数据（16-20 begin/end/帧、GameWorldRenderer 死代码、无空间裁剪、无脏标记、camera transform 重复设置）：

- [ ] **Step 1: begin/end 碎片化量化**

确认每个 begin/end 调用的精确位置（文件:行号），按绘制步骤编号并标注其必要性。计算合并后可达的 begin/end 对数（最优目标 2-3）。

- [ ] **Step 2: GameWorldRenderer 复活可行性**

对比 GameWorldRenderer 的单批次 Y-sort 设计与 GamePlayScreen 的三遍独立遍历：
- 接口兼容性：GameWorld 接口 vs GamePlayScreen 的 getTowerList/getEnemyList/getBulletList
- Y-sort 正确性：当前 GamePlayScreen 的 drawTowers→drawEnemies→drawBullets 顺序是否影响遮挡关系？
- 粒子/爆炸/MoneyPopup 是否已在 GameWorldRenderer 中实现？

- [ ] **Step 3: 空间裁剪可行性**

检查 CameraManager 的视锥体计算——能否在遍历塔/敌人/子弹时跳过屏幕外对象？估算裁剪收益（典型场景中屏幕外比例）。

- [ ] **Step 4: 脏标记优化空间**

分析哪些渲染步骤的内容在连续帧中不变：
- 地图背景（完全不变除非地图切换）
- HUD 顶部标题栏（完全不变）
- 塔按钮（仅在金钱变化或选中切换时变）
- 评估脏标记可节省的绘制调用量。

- [ ] **Step 5: 产出管线诊断章节草稿**

写入 `docs/.ui-review-2a-pipeline.md`。

### Task 2: 代码组织审查

**Scope:** 9 Screen + 7 Renderer 的职责划分与依赖关系

- [ ] **Step 1: GamePlayScreen 拆解方案**

分析 893 行的职责分布：
- 渲染代码占比（draw/drawHud/drawBackground/drawTowers/drawEnemies 等）
- 输入处理占比（onPointerDown/onPointerMoved/keyDown 等）
- 状态管理占比（update/生命周期）
- 游戏循环集成占比（gameLoop.tick）

提出拆解方案：分离出哪些类（GameRenderer/GameInputController/GameStateManager？）各自的文件和职责。

- [ ] **Step 2: UiRenderer 职责边界**

612 行的 UiRenderer 当前仅被 GamePlayScreen 使用。分析：
- 哪些方法可以提升为跨 Screen 共享组件（renderPauseOverlay 等已被多个 Screen 使用？）
- 哪些方法是纯游戏的（renderTowerButtons/renderUpgradeDialog）——应留在 GamePlayScreen 域内
- 哪些是通用 UI 组件的（renderControlButtons/renderScaleSlider）——可被其他 Screen 复用

- [ ] **Step 3: 8 个非游戏 Screen 的共同模式**

对比 MainMenu/LevelSelect/Achievement/Reward/Options/Credits/GameSave 的实现：
- 哪些代码是纯复制粘贴（标题栏 drawRect、返回按钮、背景绘制）
- 行数节省预估（若提取 TitleBar/BackButton/Panel 组件）

- [ ] **Step 4: 产出架构审查章节草稿**

写入 `docs/.ui-review-2a-architecture.md`。

### Task 3: 组件复用机会

**Scope:** 跨 Screen 的重复模式识别与提取优先级

- [ ] **Step 1: 按重复次数排优先级**

统计以下模式在 9 Screen 中的出现次数：
| 组件 | 出现次数 | 可提取度 |
|------|---------|---------|
| 标题栏（深色条+蓝顶线+标题文字） | 7 | 极高 |
| 返回按钮（drawRect+文字） | 6 | 极高 |
| 面板（深色矩形+蓝装饰线+半透明） | 5 | 高 |
| 列表+滚动条 | 3 | 中 |
| 底部快捷键条 | 2 | 中 |
| 确认对话框 | 1 | 低 |

- [ ] **Step 2: 对每个组件提提取设计方案**

- TitleBar: `drawTitleBar(renderer, title, screenW, screenH)` → 7 Screen 替换
- BackButton: `drawBackButton(renderer, x, y, w, h, 是否蓝色)` → 6 Screen 替换
- Panel: `drawPanel(renderer, x, y, w, h, alpha)` → 5 Screen 替换
- ScrollableList: 接口设计（提供 getItemCount/getItemHeight/renderItem 回调）

- [ ] **Step 3: 产出组件复用章节草稿**
