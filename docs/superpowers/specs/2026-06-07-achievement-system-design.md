# 成就系统完整重构设计

## 概述

重构桌面版成就系统，完全复刻原版 Android 版的 88 种成就，包括中文名称、详细描述、分类标签、进度显示和成就图标。

## 当前问题

| 问题 | 说明 |
|------|------|
| 缺少中文描述 | `AchievementProp` 的 `description` 字段为空，只有英文名称 |
| 描述信息未加载 | `getDescription()` 只返回进度 `(X/Y)`，没有成就说明 |
| 分类不清晰 | 所有成就混在一起，没有分类标签 |
| 视觉效果简陋 | 没有成就图标，状态指示简单 |

## 设计方案

### 1. 数据模型增强

**AchievementProp 新增字段：**

```java
private static class AchievementProp {
    String key;           // 原有：唯一标识
    String name;          // 原有：英文名称
    String nameZh;        // 新增：中文名称
    String description;   // 新增：成就描述
    AchievementCategory category;  // 新增：成就分类
    int trigger_level;    // 原有：触发等级
    int level;            // 原有：当前进度
    int saved_level;      // 原有：已保存进度
    String cached_description;  // 原有：缓存描述
}
```

**成就分类枚举：**

```java
public enum AchievementCategory {
    DIFFICULTY("难度成就", 0),   // 通关难度 2/5/8/11/14/17/20/40/60/80/100
    MAP("地图成就", 1),         // 基地/遗迹/工厂/庭院/巷道 各难度
    PERFECT("完美成就", 2),     // 完美通关 25/50/100 次
    SCORE("积分成就", 3),       // 25K/75K 俱乐部，大积分/历史高分
    SPECIAL("特殊成就", 4),     // 火箭人/枪手/吝啬鬼/大富豪等
    SURVIVAL("生存成就", 5),    // 生存模式通关 10-100 关
    VR("训练成就", 6);          // VR-A/B/C/D/E 训练任务
    
    final String label;
    final int iconIndex;
}
```

### 3. UI 层设计

**AchievementScreen 改进：**
- 分类筛选标签栏（难度/地图/完美/积分/特殊/生存/训练）
- 成就列表显示：中文名称 + 描述 + 进度条
- 已达成成就：绿色背景 + ✓ 图标
- 未达成成就：灰色背景 + 进度显示

**列表布局：**
```
┌─────────────────────────────────────────────────────┐
│ 成就                          已获得: 12/88         │
├─────────────────────────────────────────────────────┤
│ [全部] [难度] [地图] [完美] [积分] [特殊] [生存] [训练] │
├─────────────────────────────────────────────────────┤
│ 痴迷者                              ✓              │
│ 通关 5,000 关                        5000/5000      │
├─────────────────────────────────────────────────────┤
│ 通关难度 100                         进度           │
│ 通关一个地图难度等级达到 100 或更大    0/1           │
└─────────────────────────────────────────────────────┘
```

**AchievementRenderer 改进：**
- 成就达成通知：显示中文名称和描述
- 成就图标：根据分类显示不同图标

### 4. 成就触发逻辑

**触发点：**

| 触发时机 | 相关成就 |
|----------|----------|
| 地图通关 | 难度成就、地图成就、完美成就 |
| 击杀敌人 | 积分成就（25K/75K 俱乐部） |
| 游戏结束 | 特殊成就（火箭人/枪手/吝啬鬼等） |
| 生存模式 | 生存成就（通关 10-100 关） |
| VR 训练 | 训练成就（VR-A/B/C/D/E） |

### 5. 数据持久化

**现有机制无需改动：**
- `GameSaveManager.saveAchievements()` 已存在
- `AchievementProp.trySaveLevel()` 已实现增量保存

**数据存储格式：**
```
ADAchievement:Complete Any Map=1
ADAchievement:Addict=5000

```
