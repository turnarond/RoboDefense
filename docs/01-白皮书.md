# 星际塔防（Robo Defense）— 项目白皮书

> 版本：2.6.0 | 最后更新：2026-07-20

---

## 1. 项目概述

星际塔防（Robo Defense）是一款经典的 2D 塔防游戏。玩家在网格地图上策略性地放置、升级防御塔，阻止 11 种敌人突破防线。游戏包含 7 张地图、23 种防御塔、88 项成就和 23 种奖励升级。

原作为 MagicWach 开发的 Android 平台游戏（v2.5.0 Build 2900）。本项目通过 APK 逆向工程完整迁移至桌面平台，基于 libGDX 框架重构，核心逻辑 100% 平台无关。

### 关键数据

| 指标 | 数值 |
|------|------|
| 地图数量 | 7 张 |
| 防御塔类型 | 23 种（含完整升级树） |
| 敌人类型 | 11 种（含 2 种飞行 + 1 种 BOSS） |
| 子弹类型 | 15 种 |
| 成就数量 | 88 项 |
| 奖励升级 | 23 种 |
| 存档槽位 | 10 个 + 快速存档 |
| 游戏循环 | 固定 30fps 时间步长 |

## 2. 快速开始

### 环境要求

- **Java 8+**（推荐 JDK 17+）
- **操作系统**：Windows / macOS / Linux

### 运行

```bash
# 下载 JAR 后直接运行
java --enable-native-access=ALL-UNNAMED -jar desktop.jar

# JDK 8-21 直接运行（无需额外参数）
java -jar desktop.jar
```

### 从源码构建

```bash
./gradlew :desktop:dist          # 构建 → desktop/build/libs/desktop.jar
./gradlew :desktop:run           # 直接运行
```

### 操作说明

| 操作 | 键位 |
|------|------|
| 放置防御塔 | 点击右下角按钮，再点击地图格 |
| 升级/出售 | 点击已放置的塔 |
| 暂停菜单 | `ESC` |
| 快进（2x） | `空格` |
| 平移视角 | 鼠标拖拽地图 |

## 4. 技术架构

### 模块结构

```
├── core/                    # 平台无关核心逻辑（63 个 Java 文件）
│   ├── game/                # 游戏逻辑引擎
│   ├── render/              # 渲染系统（含 GameSceneRenderer 525 行）
│   ├── scene/               # 场景管理（9 个界面）
│   ├── platform/            # 平台抽象层（5 个服务接口）
│   ├── save/                # 存档系统（SQLite）
│   ├── audio/               # 音效管理
│   ├── input/               # 输入处理（含 GameInputController）
│   └── config/              # 配置数据
├── desktop/                 # 桌面启动器（LWJGL3）
└── assets/                  # 游戏资源（85 张图 + 6 音效 + 字库）
```

### 技术栈

| 组件 | 版本 |
|------|------|
| 游戏框架 | libGDX 1.12.1 |
| 桌面后端 | LWJGL 3 |
| 数据库 | SQLite (sqlite-jdbc 3.45) |
| 构建系统 | Gradle |
| 语言 | Java 8+ |
| 字体 | FreeType + SimHei |

### 平台抽象

```
PlatformServices (IoC 容器)
├── GameRenderer   — libGDX SpriteBatch + ShapeRenderer
├── GameAudio      — libGDX Sound (6 种 OGG 音效)
├── GameStorage    — libGDX Preferences + Files
├── GameInputHandler — libGDX InputProcessor 适配
└── NetworkClient  — NoOp（桌面离线）
```
