# 星际塔防（Robo Defense）— 项目白皮书

> 版本：2.6.0

---

## 1. 项目概述

星际塔防（Robo Defense）是一款经典的 2D 塔防游戏。玩家在网格地图上策略性地放置、升级防御塔，阻止 11 种敌人突破防线。游戏包含 7 张地图、23 种防御塔、88 项成就和 23 种奖励升级。

原作为 MagicWach 开发的 Android 平台游戏（v2.5.0 Build 2900）。本项目通过 APK 逆向工程完整迁移至桌面平台，基于 libGDX 框架重构，核心逻辑 100% 平台无关。

### 关键数据

| 指标 | 数值 |
|------|------|
| 地图数量 | 7 张 |
| 防御塔类型 | 23 种（含完整升级树） |
| 敌人类型 | 11 种（含 2 种飞行 + 1 种 BOSS） |
| 子弹类型 | 15 种 |
| 成就数量 | 88 项 |
| 奖励升级 | 23 种 |
| 存档槽位 | 10 个 + 快速存档 |
| 游戏图片 | 85 张 |
| 游戏音效 | 5 种 |
| 游戏循环 | 固定 30fps 时间步长 |

资源计数以 `assets/` 目录实测为准（最后核对见文档头 `最后核对日期`），本表为全仓库唯一的资源计数权威位置（见 `docs/00-文档总纲.md` §3 唯一归属矩阵）。

构建与运行命令见 `AGENTS.md`「构建与运行」一节。

## 2. 游戏内容

### 地图

| # | 名称 | 英文 | 路径数 |
|---|------|------|--------|
| 0 | 基地 | Basic Level | 1 |
| 1 | 遗迹 | The Ruins | 2 |
| 2 | 工厂 | The Factory | 2 |
| 3 | 庭院 | The Courtyard | 3 |
| 4 | VR 训练场 | VR Training | 1-10（随机） |
| 5 | 巷道 | Roadway | 1 |
| 6 | 通天塔 | Sky Tower | 2 |

### 升级树

```
机枪塔 Lv1 ─→ Lv2 ─→ Lv3 ─┬→ 防空炮 ─→ 重型防空炮
                           ├→ 火焰塔 ─→ 地狱之塔
                           └→ (铀弹→穿甲弹)

减速塔 Lv1 ─→ Lv2 ─→ Lv3 ─┬→ 传送塔 ─→ 武装传送塔
                           └→ 地雷塔 ─→ 触发地雷 ─→ 火炬塔

火箭塔 Lv1 ─→ Lv2 ─→ Lv3 ─┬→ 迫击炮 ─→ 火炮
                           └→ 地对空导弹 ─→ 先进 SAM
```

### 敌人

士兵 | 重甲兵 | 跑步者 | 卡车 | 轻坦克 | 重坦克 | 直升机 | 战斗机 | 轰炸机 | 泰坦（BOSS）| 投弹者

### 成就（88 项）

| 类别 | 数量 | 示例 |
|------|------|------|
| 难度 | 12 | 通关难度 2/5/8/.../100 |
| 地图 | 27 | 各地图通关 10/25 次 + 指定难度 |
| 完美 | 3 | 不损失生命值通关 |
| 积分 | 6 | 击杀 2.5万/7.5万 敌军 |
| 特殊 | 25 | 不用某种塔通关、单塔通关 |
| 生存 | 10 | 生存模式 10/20/.../100 关 |
| VR | 5 | 通关各等级训练任务 |
