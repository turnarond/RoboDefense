## 1. 平台服务接口

### 1.1 GameRenderer — 渲染服务

```java
public interface GameRenderer {
    // 生命周期
    void begin();
    void end();

    // 精灵绘制
    void drawSprite(String name, float x, float y);
    void drawSprite(String name, float x, float y, float w, float h);
    void drawSprite(String name, float x, float y, float r, float g, float b, float a);

    // 图形绘制
    void drawRect(float x, float y, float w, float h, float r, float g, float b, float a);
    void drawCircle(float x, float y, float r, float rr, float rg, float rb, float ra);
    void drawText(String text, float x, float y, float r, float g, float b, float a);

    // 相机
    void applyCameraTransform(float xBase, float yBase, float scale);
    float[] screenToWorld(float sx, float sy);
    float[] worldToScreen(float wx, float wy);

    // 信息
    int getScreenWidth();
    int getScreenHeight();

    // 释放
    void dispose();
}
```

### 2.3 序列化协议

```java
// 写入顺序（GameState.saveState）
public void saveState(GameSaveWriter out) {
    out.writeInt(state_index);       // 1
    out.writeInt(score);             // 2
    out.writeInt(level_bonus);       // 3
    out.writeInt(run_state);         // 4
    out.writeInt(money);             // 5
    out.writeInt(health);            // 6
    out.writeInt(starting_health);   // 7
    out.writeInt(difficulty_level);  // 8
    out.writeBoolean(survival_mode); // 9
    level_data.saveState(out);       // 10 (关卡数据)
    // tower_list: count + 每塔 5 个 int
    // enemy_list: count + 每敌 12 个 int
}
```

## 4. 场景切换接口

```java
public abstract class GameScreen implements Screen {
    protected final RoboDefenseGame game;

    // 子类实现
    protected abstract void init();
    protected abstract void update(float delta);
    protected abstract void draw(float delta);

    // 工具方法
    protected void switchScreen(GameScreen newScreen);  // 切换场景

```

### 场景间通信

```
MainMenuScreen ─→ LevelSelectScreen    [新游戏/继续游戏]
                ─→ GamePlayScreen       [继续游戏: setResumeMode()]
                ─→ GameSaveScreen       [载入存档]
                ─→ AchievementScreen    [成就]
                ─→ RewardScreen         [奖励]
                ─→ CreditsScreen        [Credits]
                ─→ OptionsScreen        [设置]

LevelSelectScreen ─→ GamePlayScreen     [configureLevel(map, diff)]

GameSaveScreen ─→ GamePlayScreen        [setLoadSlot(slotId)]

所有界面 ─→ MainMenuScreen              [返回]
```

## 5. 数据表结构（SQLite）

### save_slots — 存档元数据

```sql
CREATE TABLE save_slots (
    slot_id       INTEGER PRIMARY KEY,  -- 0=快速, 1-10=普通
    save_name     TEXT,
    level_type    INTEGER NOT NULL,     -- 地图类型
    level_num     INTEGER NOT NULL,     -- 当前关卡号
    difficulty    INTEGER NOT NULL,     -- 难度等级
    survival_mode INTEGER DEFAULT 0,
    money         INTEGER NOT NULL,
    score         INTEGER NOT NULL,
    health        INTEGER NOT NULL,
    play_time_secs INTEGER DEFAULT 0,
    created_at    INTEGER NOT NULL,
    updated_at    INTEGER NOT NULL,
    is_valid      INTEGER DEFAULT 1    -- 1=有效, 0=已删除
);
```

### save_states — 存档二进制数据

```sql
CREATE TABLE save_states (
    slot_id    INTEGER PRIMARY KEY,
    state_data BLOB NOT NULL,           -- GameState 序列化
    eyecatcher INTEGER NOT NULL,        -- 魔数 0x4146E46
    version    INTEGER NOT NULL,        -- 存档版本
    FOREIGN KEY (slot_id) REFERENCES save_slots(slot_id)
);
```

### player_progress — 玩家进度

```sql
CREATE TABLE player_progress (
    key        TEXT PRIMARY KEY,        -- 键名
    value      TEXT,                    -- 字符串值
    int_value  INTEGER,                 -- 整数值
    updated_at INTEGER NOT NULL         -- 更新时间戳
);
```

### achievements — 成就

```sql
CREATE TABLE achievements (
    id          TEXT PRIMARY KEY,       -- 成就键名
    unlocked_at INTEGER,               -- 解锁时间戳
    progress    INTEGER DEFAULT 0      -- 进度计数
);
```
