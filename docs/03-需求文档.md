# 星际塔防（Robo Defense）— 功能需求文档

> 版本：2.5.0 (Build 2900)
> 核对时效只在头部元信息 `最后核对日期` 一处登记，局部复核范围见文末「变更」行；
> 正文不重复声明日期，以免与元信息互相腐化。

---

## 1. 产品概述

星际塔防是一款经典的 2D 塔防游戏，玩家通过在网格地图上放置、升级防御塔来阻止敌人突破防线。游戏支持多种地图、难度等级、生存模式、成就系统和积分奖励系统。

**目标平台**：Android（minSdk 14，targetSdk 28）
**屏幕方向**：横屏（landscape）

---

### 3.2 关卡选择（LevelSelectActivity）

| ID | 需求 | 描述 |
|----|------|------|
| F-SEL-01 | 地图选择 | 提供7种地图：基地、遗迹、工厂、庭院、巷道、通天塔、VR训练场地 |
| F-SEL-02 | 难度选择 | 拖动条选择难度等级（0 ~ 最高已解锁等级） |
| F-SEL-03 | 难度解锁 | 通关当前难度后解锁下一难度等级，最高无上限 |

| F-SEL-07 | 地图代码 | 混合器模式可输入5位种子码（0-9, A-E）或点"随机" |

### 3.3 核心战斗（GameActivity）

#### 3.3.1 游戏状态

| ID | 需求 | 描述 |
|----|------|------|
| F-GAME-01 | 运行状态 | 游戏有6种状态：运行中(0)、失败(1)、胜利(2)、暂停(3)、快进(4)、未开始(5) |
| F-GAME-02 | 游戏开始 | 点击屏幕开始游戏，显示欢迎信息和操作说明 |
| F-GAME-03 | 游戏失败 | 生命值降至0时游戏结束，显示"游戏结束" |
| F-GAME-04 | 游戏胜利 | 所有波次敌人被消灭后显示"恭喜: 你赢了!"并展示积分总结 |
| F-GAME-05 | 暂停 | 点击暂停按钮或按菜单键暂停 |
| F-GAME-06 | 快进 | 点击快进按钮以2倍速运行；可在设置中配置关卡间快进行为 |

#### 3.3.2 防御塔系统

| ID | 需求 | 描述 |
|----|------|------|
| F-TOWER-01 | 塔类型 | 3种基础塔（枪塔、减速塔、火箭塔），通过升级衍生为23种塔 |
| F-TOWER-02 | 放置 | 从底部塔按钮拖拽到地图空格放置；不能阻断所有敌人路径 |
| F-TOWER-03 | 升级 | 点击已放置的塔弹出升级对话框，最多3个升级方向 |
| F-TOWER-04 | 出售 | 升级对话框中可出售塔获得部分金钱返还 |
| F-TOWER-05 | 路径验证 | 放置阻挡型塔前验证不会完全阻断敌人通路 |
| F-TOWER-06 | 攻击逻辑 | 每座塔按射击延迟间隔瞄准范围内的敌人并发射弹药 |
| F-TOWER-07 | 目标选择 | 塔优先攻击范围内最近的有效目标；部分塔仅攻击地面/空中单位 |
| F-TOWER-08 | 攻击范围显示 | 放置和升级时可选择显示塔的攻击范围圈 |

**塔升级树**：

```
枪塔(Lv1) → 中程炮(Lv2) → 重炮(Lv3)
                            ├→ 防空炮(Lv4) → 重型防空炮(Lv5)
                            └→ 火焰塔(Lv4) → 地狱之塔(Lv5)

减速塔(Lv1) → 升级减速塔(Lv2) → 先进减速塔(Lv3)

火箭塔(Lv1) → 中级火箭(Lv2) → 重型火箭(Lv3)
                               ├→ 地对空导弹(Lv4) → 先进空中导弹(Lv5)
                               └→ 迫击炮(Lv4) → 炮塔(Lv5)

传送塔(需解锁) → 武装传送塔

地雷塔(需解锁) → 武装雷

火炬塔(需解锁，独立塔)
```

## 4. 非功能需求

| ID | 需求 | 描述 |
|----|------|------|
| NF-01 | 帧率 | 默认30fps，可选降帧模式 |
| NF-02 | 性能自适应 | 性能不足时自动跳帧（skip_level 0~40），减少烟雾粒子和火焰数量 |

| NF-05 | 分辨率适配 | 根据屏幕DPI动态计算网格大小（HD:70px / SD:40px / Tiny:30px） |
| NF-06 | 中文本地化 | 所有用户界面文本为简体中文 |
| NF-07 | 向后兼容 | 支持 Android 4.0 (API 14) 及以上 |
