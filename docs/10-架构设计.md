# 星际塔防（Robo Defense）— 架构设计

> 版本：2.5.0 | 最后更新：2026-07-15

---

## 1. 整体架构

```
┌──────────────────────────────────────────────────┐
│                  Desktop Launcher                 │
│         LWJGL3Application + 窗口配置              │
└──────────────────┬───────────────────────────────┘
                   │ 注入 PlatformServices
┌──────────────────▼───────────────────────────────┐
│              RoboDefenseGame                      │
│  主游戏类（ApplicationAdapter）                   │
│  ├── 字体加载（FreeType + SimHei）                │
│  ├── 存档初始化（SQLite）                         │
│  ├── 场景切换（setScreen）                        │
│  └── 生命周期（create/render/resize/dispose）      │
└──────────────────┬───────────────────────────────┘
                   │
    ┌──────────────┼──────────────┐
    ▼              ▼              ▼
 GameScreen    GameScreen     GameScreen
 (MainMenu)   (LevelSelect)  (GamePlay)
    │              │              │
    └──────────────┴──────────────┘
                   │ 依赖
    ┌──────────────┼──────────────┐
    ▼              ▼              ▼
 game/          render/        platform/
 (游戏逻辑)     (渲染系统)      (平台抽象)
```

### 设计原则

1. **平台无关**：核心逻辑不依赖 Android/libGDX API
2. **接口隔离**：5 个平台服务接口，各平台注入具体实现
3. **对象池化**：Enemy/Tower/Bullet/GameEvent 使用链表池避免 GC
4. **事件驱动**：12 种 GameEvent 类型解耦游戏逻辑与 UI 渲染
5. **固定时间步长**：30fps 纳秒累加器，逻辑与渲染分离

## 2. 模块设计

### 2.1 core/game — 游戏逻辑引擎

```
GameState         ← 核心状态机（运行/暂停/快进/胜利/失败）
├── LevelData     ← 关卡参数 + 波次数据
│   └── LevelDataGenerator ← 100 关程序化生成
├── MovementGrid[] ← BFS 寻路（每条路径一个）
├── CollisionGrid  ← 空间分区（塔目标检测，96px/cell）
├── GridObjectOrder ← Y 排序链表（渲染顺序）
├── Enemy (链表池)  ← 11 种敌人状态机
├── GameTower (链表池) ← 23 种塔射击逻辑
├── Bullet (链表池)   ← 15 种弹道
└── GameEvent[12]    ← 事件队列（按类型分桶）
```

### 2.2 core/render — 渲染系统

```
CameraManager    ← 正交相机（平移/缩放/坐标转换）
GameLoop         ← 固定 30fps 时间步长 + 纳秒累加器
HudRenderer      ← 顶部状态栏（等级/积分/金钱/生命）
UiRenderer       ← UI 控件（按钮/升级框/暂停菜单）
GameWorldRenderer ← 世界渲染（已弃用，实际渲染在 GamePlayScreen）
```

### 2.3 core/scene — 场景管理

```
GameScreen (基类) ← libGDX Screen 接口
├── MainMenuScreen     ← 主菜单（开始/继续/存档/成就/奖励/Credits/退出/设置）
├── LevelSelectScreen  ← 关卡选择（地图轮播 + 难度滑块 + 模式开关）
├── GamePlayScreen     ← 游戏主界面（渲染/输入/UI 总控）
├── GameSaveScreen     ← 存档管理（加载/保存槽位）
├── AchievementScreen  ← 成就浏览（分类标签 + 滚动列表）
├── RewardScreen       ← 奖励商店（23 种升级购买）
├── CreditsScreen      ← 致谢信息
└── OptionsScreen      ← 设置开关（13 项）
```

### 2.4 core/platform — 平台抽象层

```
PlatformServices (聚合)
├── GameRenderer   ← 渲染抽象
│   └── LibGdxRenderer (SpriteBatch + ShapeRenderer)
├── GameAudio      ← 音频抽象
│   └── LibGdxAudio (Sound)
├── GameStorage    ← 存储抽象
│   └── LibGdxStorage (Preferences + Files)
├── GameInputHandler ← 输入抽象
│   └── GameInputHandlerImpl → LibGdxInputAdapter
└── NetworkClient  ← 网络抽象
    └── NoOpNetworkClient
```

### 2.5 core/save — 存档系统

```
GameSaveManager (接口)
└── SQLiteSaveManager (SQLite 实现)
    ├── save_slots 表    ← 存档元数据
    ├── save_states 表   ← GameState 二进制序列化
    ├── player_progress 表 ← 玩家进度/偏好
    └── achievements 表  ← 成就数据

PlayerPrefs ← 基于 GameSaveManager 的偏好存储
GameSaveData / JsonSaveSerializer ← JSON 存档格式
```

## 3. 数据流

### 3.1 游戏主循环

```
GameLoop.tick()
  └→ GameState.nextState()
       ├─ recycleGameEvents()         ← 回收完成的事件
       ├─ advanceActiveEnemiesState() ← 敌人移动 + 检测到达出口
       ├─ advanceTowersState()        ← 塔瞄准 + 射击（创建 Bullet）
       ├─ advanceBulletsState()       ← 子弹移动 + 碰撞检测
       ├─ advanceLevelState()         ← 波次推进 + 部署新敌人
       └─ grid_order.ensureSorted()   ← Y 排序维护

每帧渲染（60fps）
  └→ draw()
       ├─ drawBackground()         ← 地图背景 + 相机变换
       ├─ drawTowers()            ← 塔精灵（底座 + 转头）
       ├─ drawEnemies()           ← 敌人精灵 + 血条 + 状态效果
       ├─ drawBullets()           ← 子弹精灵
       ├─ drawEnemyDefeatedEvents() ← 金钱/积分飘字
       ├─ drawActiveTowerPreview()  ← 拖拽塔预览
       ├─ drawHud()               ← HUD 状态栏
       ├─ drawTowerButtons()      ← 塔选择按钮
       └─ uiRenderer.renderUpgradeDialog() ← 升级对话框
```

### 3.2 存档/加载流程

```
保存:
  GameState.saveState(GameSaveWriter)
    → state_index, score, money, health, level_data
    → tower_list (每塔: gridx, gridy, type, shot_delay)
    → enemy_list (每敌: 12 个属性)
    → SQLite BLOB (魔数 0x4146E46 + 版本号验证)

加载:
  SQLite BLOB → GameState.loadState(GameSaveReader)
    → 缓存所有标量 → initGame(重建网格) → 重建塔/敌链表
    → 恢复被 initGame 重置的标量
    → calcPaths(重建寻路)
```

### 3.3 事件系统

```
12 种事件类型，按类型分桶（链表）:
  0: MESSAGE           ← 文字消息
  1: ENEMY_DEFEATED    ← 敌人击败（积分飘字）
  2: MONEY_CHANGED     ← 金钱变化
  3: GAME_INIT         ← 游戏初始化
  4: HEALTH_CHANGED    ← 生命值变化
  5: LEVEL_BONUS_LOST  ← 关卡奖励丢失
  6: TOWERS_CHANGED    ← 塔变化（触发路径重算）
  7: SCORE_SAVED       ← 积分结算
  8: PARTICLE          ← 粒子效果（烟雾/火焰）
  9: EXPLOSION         ← 爆炸动画
 10: ACHIEVEMENT_EARNED ← 成就通知
 11: GAME_LOAD_SUCCESS  ← 加载成功
```

## 4. 关键算法

### 4.1 BFS 寻路（MovementGrid）

```
calcPaths(tower_list):
  1. initGrid: 标记边界(6)、塔(5)、障碍物(6)、终点(7)
  2. 从终点周围开始 BFS，反向扩散标记方向(1-4)
  3. 每格标记为 0=未访问/1-4=移动方向
  4. pushPendingNodes: 检查四方向邻居，值=0 则入队

checkTowerPlacement(towerX, towerY):
  1. 创建 trialGrid，放置塔(5)
  2. findPathGreedy: BFS 检查起点→终点连通性
  3. 返回是否可达
```

### 4.2 波次生成（LevelDataGenerator）

```
generate(seed, difficulty, paths, survival):
  for 100 关:
    health = base + quadratic_growth
    features = random(0-127):
      bits 0-1: 分组数 1-4
      bits 2-4: TOUGH_MASK（+25% 血量）
      bits 5-6: TYPE_MASK（控制飞行/地面/混合）
    for each group:
      enemy_skip = random(0-10) → 跳过候选类型
      找到第一个有效的敌人类型 → addGroup()

编码: (inner_delay<<24)|(init_delay<<15)|(type<<10)|(count<<3)|path
```

### 4.3 混合器模式（MixerLevelGenerator）

```
MixerLevelGenerator(mixerSeed, width, height):
  numPaths = |seed| % 10 + 1  (1-10 条路径)
  末位=5 → isFixedPath=true, numPaths=1

createStartPaths():
  随机在四边墙壁生成起点（编码: wall_number<<8 | offset）
  确保不重复

createObstacles():
  随机生成 0-10 个 1×1/1×2/2×1/2×2 障碍物
  每个障碍物在所有路径上验证可达性（checkObstacleLayout）
```

### 4.4 性能自适应（PerformanceMonitor）

```
skipLevel: 0-40（帧丢失递增，恢复递减）
graceCounter: 丢帧后 15 帧不检测（防抖动）
recoveryCounter: 持续正常达到阈值才降低 skipLevel

质量档位:
  0 (skip 0-1):   烟雾 30, 火焰 5,  爆炸 100%
  1 (skip 2-3):   烟雾 20, 火焰 4,  爆炸 100%
  2 (skip 4-7):   烟雾 10, 火焰 2,  爆炸 75%
  3 (skip 8-15):  烟雾 0,  火焰 1,  爆炸 50%
  4 (skip 16-40): 烟雾 0,  火焰 1,  爆炸 0%
```
